# Serum metabolites and postpartum depression

Manuscript: PSY-D-26-02984, Psychiatry Research.

Download [PPD_MR_reproducibility_final.zip](PPD_MR_reproducibility_final.zip) for the final analysis scripts, data and results corresponding to the revised manuscript and supplementary materials. Extract the archive and run commands from the `ppd-metabolite-mr` directory.

The package contains final primary and sensitivity results for 485 analyzed metabolites, complete retained SNP-metabolite records for those analyses, the 977-row joint input for the 30-exposure MVMR analysis, supporting diagnostic scripts and outputs, and the consolidated supplementary Tables S1-S30.

Final results are in `data/primary_results.tsv`, `data/sensitivity_results.tsv` and `output/mvmr_results.tsv`. The package README documents input locations, reproduction commands, software information and remaining historical reproducibility limits.
